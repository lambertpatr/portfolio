The Secret to 1-Minute Auto-Refresh in Looker Studio (Free)

By default, Looker Studio caches Google Sheets queries for 15 minutes. To force 1-minute updates:

  1. In your Google Sheet, add an Apps Script trigger running every minute that appends incoming data.
  2. In Looker Studio, go to Resource → Manage added data sources → Edit → Data freshness → Set to "Every 15 minutes" (the native minimum).
  3. To auto-refresh the visual on office screens or browsers every 60 seconds, append ?refresh=60 to your embed URL or use the automated polling script included in this portfolio showcase.
