01. Reasonable Assurance Gates

Never assumes a script succeeded just because it finished. Scripts check $LASTEXITCODE, assert affected row counts, inspect error logs, and verify database states post-execution.

02. Alert Triage & Escalation

Structured playbook for handling failed Agent jobs, log growth spikes, blocking queries, or connection drops, documenting root causes and notifying leads immediately with concise diagnostic dumps.

03. Safe Script Execution Protocol

Adheres strictly to instructions: executes scripts within explicit transaction blocks (BEGIN TRAN / COMMIT), confirms target database context (USE [DB]), and retains complete audit logs.
