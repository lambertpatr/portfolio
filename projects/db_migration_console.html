Pillar 1: Driver-Level Read-Only
ApplicationIntent & Snapshot Isolation

SQL Server connections enforce ApplicationIntent=ReadOnly and snapshot isolation / WITH (NOLOCK). Oracle sessions execute SET TRANSACTION READ ONLY immediately upon handshake.

Pillar 2: Client AST AST Parser
Query Whitelisting & Static Analysis

Client-side query gate disallows DDL and DML statements (INSERT, UPDATE, DELETE, DROP, ALTER) before sending packets down the wire.

Pillar 3: Memory-Efficient Streaming
Server-Side Cursors & Parquet

Streams tables in 25,000-row chunks directly into compressed Apache Parquet or Gzipped CSV files, preventing high memory usage on multi-gigabyte databases.
