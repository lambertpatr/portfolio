Authenticated Scraping & Download Engine Architecture

Designed for reliability against session timeouts, bot mitigation, and large file streams.

1. Session & Auth Persistence

Handles Steam OpenID / Form logins, stores encrypted session cookies and Bearer tokens in session_store.json. Automatically triggers re-login on 401/403 expiry.

2. Chunked Stream Downloader

Streams .dem.gz files in 64KB chunks to keep memory usage minimal, tracks real-time progress, and validates SHA-256 integrity before unpacking.

3. On-Demand REST / Queue API

Built with FastAPI and async background workers. Clients or Discord bots call POST /api/v1/demos/download and poll task status until ready.

Execution Flow:

User Request (Match ID) ➔ Check Session Validity ➔ (Auto-Refresh Auth if expired)
➔ Query Match API Endpoint with Auth Header ➔ Obtain Signed CDN Download Link
➔ Stream .dem.gz in background ➔ Verify SHA-256 Checksum ➔ Gzip Decompress .dem ➔ Trigger Analytics Parser
